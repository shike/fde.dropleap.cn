# 上线清单（fde-directory → 生产）

> 目标：把 [http://localhost:3000](本地站点) 发布到你已有 ICP 备案的国内服务器。
> 架构与 content-studio 同款：rsync 代码 → systemd 常驻 → nginx 反代 + HTTPS。

## 你需要拍板/提供的（按顺序）

- [ ] **1. 部署目标**：是否就部署在 content-studio 那台服务器（ubuntu@119.45.236.120）？
      是 → 我直接复用 `~/.ssh/content_studio_deploy` 密钥和现成链路；否 → 给我 `user@host` + 密钥。
- [ ] **2. 域名**：品牌正式名定了吗（SPEC 待定项）？给我域名，我配 nginx server_name；
      DNS 解析到服务器 IP 后我再跑 HTTPS（certbot 或复用现有证书方案）。
- [ ] **3. 品牌正式名**：站点标题/页脚现在写的占位名「中国 FDE 名录」，确认或替换。
- [ ] **4. 主理人页文案**：一句话身份 + 为什么做这个名录 + 联系入口（/about 页占位待填）。
